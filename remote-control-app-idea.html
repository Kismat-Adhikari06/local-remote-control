Remote Control App

Control your laptop's mouse & keyboard from your Android phone over WiFi — no browser needed on the phone.

🎯 What It Does

  • Mouse control — touchpad-style cursor movement, left/right click, scroll
  • Keyboard input — type text, send hotkeys (Ctrl+C, Alt+Tab, etc.)
  • Works over WiFi — both devices on the same local network, zero internet dependency
  • Native Android app — no browser, no web view gimmicks. A real installed APK.
  • Lightweight desktop server — minimal footprint, runs in the background

⚙️ Tech Stack — Detailed

🖥️ Desktop Server (Python)

  • Python 3.11+ — lightweight, ships with most systems, no heavy runtime
  • websockets — async WebSocket server for real-time communication
  • pyautogui — cross-platform mouse & keyboard emulation
  • asyncio — native async event loop, handles multiple clients
  • qrcode + Pillow — generate a QR code with the server's IP for easy phone connection
  • Packaging: PyInstaller → single `.exe` / binary, no Python install needed

📱 Android App (Flutter)

  • Flutter 3.x (Dart) — compiles to native ARM code, no JVM/Android bloat
  • web_socket_channel — WebSocket client for Flutter
  • Custom touchpad widget — gesture detector for pan (move), tap (click), long-press (right-click), pinch (scroll)
  • Keyboard input overlay — custom text field + hotkey buttons
  • Connection screen — scan QR code or type IP manually
  • Packaging: `flutter build apk` → installable APK, or AAB for Play Store

📡 Communication Protocol

All messages are JSON over WebSocket. Lightweight, human-readable, easy to debug.

Message TypePayloadDescription
mouse_move{ "dx": 50, "dy": 30 }Relative cursor movement (touchpad-style)
mouse_click{ "button": "left" }Click a mouse button
mouse_scroll{ "clicks": -3 }Scroll up/down (negative = down)
key_press{ "key": "enter" }Press & release a key
key_type{ "text": "Hello!" }Type a string of text
hotkey{ "keys": ["ctrl", "c"] }Send a keyboard shortcut
ping{}Keep-alive / latency check

Error handling, reconnection logic, latency display, UI polish, dark theme, vibration on tap.

PyInstaller → single .exe for desktop; flutter build apk → Android APK.

🤔 Why This Stack?

  • Python (not Kotlin/Java) — lightweight runtime, no JVM overhead, the server is just a script. Can be bundled into a 10 MB .exe.
  • Flutter (not Kotlin) — compiles directly to native ARM code, no Android framework bloat. Dart is way lighter than Kotlin. One codebase for future iOS support too.
  • WebSockets (not HTTP polling) — real-time bidirectional, low latency, persistent connection. Perfect for mouse movement (which needs ~60 updates/sec).
  • No browser — the Flutter app is a native Android app. It does not open a browser, does not need a web view. It's a real installed app with its own icon.
  • No cloud / no internet — everything runs on your local WiFi. Zero latency outside your network, zero privacy concerns.

🔄 Alternatives Considered

  • Electron (Desktop) — way too heavy (bundles entire Chromium). Python server is ~10 MB vs Electron's ~150 MB.
  • Kotlin/Android Native (Phone) — heavy Android SDK, more boilerplate, slower to prototype. Flutter is faster to build and lighter at runtime.
  • React Native (Phone) — JavaScript bridge adds latency. Flutter compiles to native code = smoother touchpad experience.
  • PWA / Web App (Phone) — you said no browser. A PWA still runs in the browser, can't access system-level features properly.
  • Rust / Go (Desktop) — overkill for this project. Python has the best ecosystem for mouse/keyboard automation out of the box.
